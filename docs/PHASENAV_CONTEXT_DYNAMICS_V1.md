# PhaseNav Context Dynamics Canon v1

## Canonical statement

Context in PhaseNav is a scalar potential field on the operational phase torus,
not a free-form text label:

\[
C\equiv U_C:T^{36}\rightarrow\mathbb R_{\ge0}.
\]

The field is generated by weighted PhaseNav anchors. Each anchor carries a
canonical 36D phase vector and semantic mass inherited from the H2048 source
state.

## Vectors

Three vector types are separated:

1. **Position vector** \(\phi\in T^{36}\): gauge-locked phase coordinates.
2. **Tangent vector** \(v\in T_\phi T^{36}\): velocity or semantic transport.
3. **Force vector** \(F_C(\phi)=-\nabla U_C(\phi)\): contextual direction.

This prevents phase positions from being confused with velocities, forces or
repository paths.

## Context density

For anchor \(a\), define the smooth periodic chord metric

\[
d_c^2(\phi,a)=\frac{2}{36}\sum_{i=1}^{36}
\left[1-\cos(\phi_i-a_i)\right].
\]

With canonical bandwidth

\[
h_C=4\eta_M,\qquad \eta_M=36\kappa,
\]

the kernel and normalized contextual density are

\[
K_a(\phi)=\exp\left[-\frac{d_c^2(\phi,a)}{2h_C^2}\right],
\]

\[
\rho_C(\phi)=\frac{\sum_a w_aK_a(\phi)}{\sum_aw_a}.
\]

Default anchor weight is its semantic mass. Explicit weights are allowed only
as recorded context inputs and are included in the context digest.

The historical `memory_density` count in `phase_memory.py` remains a finite
neighbour statistic. `rho_C` is the smooth canonical field density used by the
dynamical equations; the two values must not be silently interchanged.

## Potential

The canonical contextual potential is the information potential

\[
U_C(\phi)=-\kappa\ln\rho_C(\phi).
\]

Dense coherent context therefore forms a low-potential basin. Sparse context
raises the potential. The analytic gradient is

\[
\frac{\partial U_C}{\partial\phi_i}
=
\frac{\kappa}{36h_C^2}
\frac{\sum_aw_aK_a\sin(\phi_i-a_i)}{\sum_aw_aK_a}.
\]

The contextual force is

\[
F_C=-\nabla U_C.
\]

## Density dispersion and viscosity

The local contextual dispersion is

\[
\sigma_C^2(\phi)=
\frac{\sum_aw_aK_a(\phi)d_c^2(\phi,a)}
{\sum_aw_aK_a(\phi)}.
\]

The canonical viscosity is

\[
\mu_C(\phi)=
\kappa\left[
1+\rho_C(\phi)
\left(1+\frac{\sigma_C^2(\phi)}{h_C^2}\right)
\right].
\]

It has a positive floor \(\kappa\). Density contributes contextual binding;
dispersion contributes resistance caused by competing local directions.
Viscosity is therefore not another name for density.

## Orbits

For a concept with semantic mass \(m\), the canonical orbit is the damped
second-order trajectory

\[
m\ddot\phi+\mu_C(\phi)\dot\phi=-\nabla U_C(\phi).
\]

The implementation uses deterministic semi-implicit Euler integration and
records at every step:

- phase position;
- tangent velocity;
- density;
- potential;
- viscosity;
- gradient norm;
- kinetic energy;
- total energy;
- exact context digest.

An orbit is a computed trajectory and does not itself authorize a mutation of
cards, glossary or repository files.

## Attractors

A contextual attractor is a converged mode of \(\rho_C\), equivalently a local
minimum candidate of \(U_C\), with small fixed-point residual
\(\|\nabla U_C\|\). Modes are found by circular mean shift on \(T^{36}\) and
clustered only within the internal distinguishability scale.

The attractor record contains:

- its 36D vector;
- supporting anchor IDs;
- density;
- potential;
- viscosity;
- gradient residual;
- strength \(\rho_C/\mu_C\).

This definition is distinct from:

- maximum order parameter \(R\);
- maximum semantic mass;
- nearest self-dual H2048 state;
- a historical object named `identity_attractor`.

Those quantities may coincide in a specific context, but the canon does not
identify them by definition.

## Provenance

Every context has a SHA-256 digest over:

- bandwidth;
- sorted anchor IDs;
- weights;
- semantic masses;
- 36D anchor vectors.

Orbit receipts carry this digest. Reproduction therefore requires the same
context field, not merely the same initial phrase.
