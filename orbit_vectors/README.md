# orbit_vectors

Executable full-36D PhaseNav orbit surface.

`orbit_vector` means a finite 36-coordinate phase vector in `T^36`. The historical
11-feature labels are not aliases for the first 11 phase coordinates.

Files:
- `catalog.py` — validated canonical orbit catalogue;
- `export.py` — JSONL exporter;
- `__init__.py` — import surface.
